# Security Policy

`fluency.lat` takes security and data privacy seriously.

## ✉️ Reporting a Security Vulnerability

If you discover a potential security vulnerability within `fluency.lat`, please report it directly and privately to:

**Email**: [safe.jcoronado@gmail.com](mailto:safe.jcoronado@gmail.com)

Please include:
- A description of the issue and potential impact.
- Steps or proof-of-concept to reproduce the vulnerability.

We aim to acknowledge receipt within 48 hours and work quickly to address any reported issues.
